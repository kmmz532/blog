# 記事の書き方

## 記事ファイル

記事は `blog-article/content/posts/<slug>.md` に置きます。ファイル名の `<slug>` が URL になります（`/posts/<slug>/`）。

```markdown
---
title: "記事タイトル"
date: 2026-10-29T12:00:00+09:00
categories: ["tech"]
tags: ["hugo", "github"]
summary: "一覧と OGP に使う概要"
---

本文（Markdown）
```

- `slug` は英小文字・数字・ハイフンのみ（1〜80 文字）。
- `categories` は `tech` `diary` `misc` `devlog` のどれか。
- 日時は日本時間で書きます。`+09:00` を付けてください。
- `aliases` は手で書かなくて構いません。slug を変えたとき自動で追加されます。

## 管理画面で書く

1. ログインしてから、ヘッダーの「新規記事」を押す。既存記事は詳細ページの「この記事を編集」から開く。
2. タイトル、slug、投稿日時、カテゴリ、タグ、概要、本文を入力する。
3. 右側のプレビューで表示を確かめる。
4. 「公開」を押す。`blog-article` にコミットされ、1〜2 分後に反映されます。

### 下書き

入力内容は自動で下書きとして保存されます。下書きはこの端末のブラウザにだけあります。

- 同じ記事を開いたとき、下書きがあれば復元するか聞かれます。
- 公開すると下書きは消えます。
- 編集画面の「下書き」一覧から別の記事の下書きを開けます。

### 画像

「画像を挿入」でファイルを選ぶと、長辺 1600px・WebP に変換して `static/images/<yyyy>/` に保存し、カーソル位置に `![代替文](/images/…)` を挿入します。

- 変換後のサイズが 1MB を超える画像は保存できません。
- GIF と SVG は変換せず、1MB 以下のものだけ保存できます。
- 画像は保存された時点で `blog-article` にあり、表示されるのはデプロイ後です。

### slug の変更

既存記事の slug を変えて公開すると、新しい slug の記事を作ってから古いファイルを削除します。古い URL（`/posts/<旧slug>/`）は新しい URL へ転送されます。

古いファイルの削除に失敗した場合は、画面に表示されます。その場合は `blog-article` から手で削除してください。

### 削除

編集画面の「削除」で、確認のため slug を入力すると削除されます。

### 競合

同じ記事を別のタブや別の端末で先に更新すると、公開時に「他で更新されています」と表示され、上書きは行われません。画面を読み直してから、変更を入れ直してください。
