# 記事の書き方

記事は Markdown で書きます。編集画面の「プレビュー」で、公開後と近い見た目を確認できます。

## 埋め込みとカード

記法は 1 行に 1 つだけ書きます。段落の途中に混ぜないでください。

| 記法 | 出るもの | 備考 |
| --- | --- | --- |
| `{{< link-card url="https://..." >}}` | 記事のタイトル・概要・サムネイルのカード | 取れなければ通常のリンクになる |
| `{{< youtube id="11字のID" >}}` | YouTube の動画（16:9） | ID だけを書く。URL は不可 |
| `{{< tweet url="https://x.com/ユーザー名/status/番号" >}}` | X の投稿の埋め込み | X の公式スクリプトを読み込む。単独の行に置く |
| `{{< instagram url="https://www.instagram.com/p/コード/" >}}` | Instagram の投稿（iframe） | `/reel/` の URL も可 |
| `{{< facebook url="https://www.facebook.com/..." >}}` | Facebook の投稿（iframe） | 公開されている投稿だけ表示される |
| `{{< vimeo id="数字" >}}` | Vimeo の動画（16:9） | ID だけを書く |
| `{{< niconico id="sm9 など" >}}` | ニコニコ動画（16:9） | ID だけを書く |
| `{{< soundcloud url="https://soundcloud.com/ユーザー名/曲" >}}` | SoundCloud の曲（音声） | 曲の URL を書く |

GitHub のリポジトリや記事の URL は、`link-card` にすればカードになります。gist の埋め込みはスクリプトが要るので、今は対応していません。

### URL を貼り付けると

本文欄に URL 1 つだけを貼り付けると、自動で `{{< link-card url="..." >}}` の記法になります。

- Ctrl+Z を 1 回押すと、記法が URL に戻ります。もう 1 回で URL も消えます。
- 画像のファイルを貼ったときは、従来どおり画像として入ります。
- 貼り付けた記法の前後には改行を入れません。文の途中に貼ったときは、記法の前後で改行して、記法だけの 1 行にしてください。

### YouTube の ID

`https://www.youtube.com/watch?v=dQw4w9WgXcQ` の `v=` の後ろ（この例では `dQw4w9WgXcQ`）の 11 字です。ID の形が違うと、記事に赤い文字でエラーが出ます。

### コードの中に書きたいとき

説明のために記法そのものを見せたいときは、`{{</* link-card */>}}` のように `{{</*` と `*/>}}` で囲みます（Hugo のエスケープ）。このときは実行されません。

コードブロック（``` で囲んだ部分）の中の記法は、編集画面のプレビューではカードにしません。公開後の扱いは、確認するまで保証しません。

## 画像

### アップロード

次のどれでも画像を上げられます。画像は `blog-article` の `static/images/<年>/` に保存され、本文には `![名前](/images/年/ランダムな名前.webp)` が入ります。

| 方法 | 確認ダイアログ | 備考 |
| --- | --- | --- |
| ツールバーの画像ボタン | なし | ファイルを選ぶ |
| 本文欄へ Ctrl+V / Cmd+V | あり | クリップボードの画像 |
| 本文欄へドラッグ＆ドロップ | あり | |
| ツールバーの「画像の一覧」 | なし | 複数のファイルを選べる。ドロップも可 |

- 上げる前に、長辺 1600px に縮小して WebP（品質 0.85）に変換します。変換後に 1MB を超えると保存できません。GIF と SVG は変換せず、1MB までです。
- 貼り付けとドロップは、誤って貼った画像を上げないよう、プレビューと「表示サイズ」を選ぶ確認ダイアログが出ます。`blog-article` は公開リポジトリなので、**上げた時点で誰でも見られます**。個人情報などが写っていないか確認してください。
- 上げた画像を後から消しても、Git の履歴には残ります。

### 表示サイズ

本文では、画像の説明（alt）の末尾に `|` と幅（px）を付けると、その幅で表示します。

```
![設計図|480](/images/2026/abcd1234.webp)
```

- 選べる幅は、確認ダイアログと画像の一覧の選択欄から入れられます（小 320 / 中 480 / 大 720）。数字は手で書き換えても構いません（2〜4 桁）。
- 付けなければ元の大きさです。ページの幅より大きい画像は、ページの幅に収まります。

### 画像の管理

- 編集画面: ツールバーの「画像の一覧」で開くダイアログ。画像を選んで本文のカーソル位置に挿入、URL のコピー、削除ができます。挿入しても閉じないので、続けて入れられます。
- 管理画面: `/admin/images/`（`/admin/` の「画像」タブ）。一覧、アップロード、URL のコピー、削除。
- 削除は 1 件ずつです。その画像を使っている記事があるかは調べないので、確認の文面を読んでから消してください。反映まで 1〜2 分かかります。

### プレビューの画像

公開前の画像は `/images/...` では開けないので、プレビューでは GitHub 上の画像を直接表示します。上げた直後の画像は手元のデータで表示するので、すぐ見えます。

### サムネイル

一覧のカードの画像は、本文の最初の画像が自動で使われます。編集画面の「サムネイル」で、本文の画像から選ぶか、別の画像を上げて指定できます。

## 編集画面のそのほか

- **並べて表示**: 画面が広い（1400px 以上）ときだけ使えます。このときだけ、ツールバーの右端にスクロール同期の切り替えボタンが出ます。オフにすると、本文欄とプレビューを別々にスクロールできます。選んだ状態は、この端末に覚えます。
