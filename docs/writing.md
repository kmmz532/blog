# 記事の書き方

記事はMarkdownで書きます。編集画面の「プレビュー」で、公開後と近い見た目を確認できます。

## 埋め込みとカード

記法は1行に1つだけ書きます。段落の途中に混ぜないでください。

| 記法 | 出るもの | 備考 |
| --- | --- | --- |
| `{{< link-card url="https://..." >}}` | 記事のタイトル・概要・サムネイルのカード | 取れなければ通常のリンクになる |
| `{{< youtube id="11字のID" >}}` | YouTubeの動画（16:9） | IDだけを書く。URLは不可 |
| `{{< tweet url="https://x.com/ユーザー名/status/番号" >}}` | Xの投稿の埋め込み | Xの公式スクリプトを読み込む。単独の行に置く |
| `{{< instagram url="https://www.instagram.com/p/コード/" >}}` | Instagramの投稿（iframe） | `/reel/` のURLも可 |
| `{{< facebook url="https://www.facebook.com/..." >}}` | Facebookの投稿（iframe） | 公開されている投稿だけ表示される |
| `{{< vimeo id="数字" >}}` | Vimeoの動画（16:9） | IDだけを書く |
| `{{< niconico id="sm9など" >}}` | ニコニコ動画（16:9） | IDだけを書く |
| `{{< soundcloud url="https://soundcloud.com/ユーザー名/曲" >}}` | SoundCloudの曲（音声） | 曲のURLを書く |

GitHubのリポジトリや記事のURLは、`link-card` にすればカードになります。gistの埋め込みはスクリプトが要るので、今は対応していません。

### URLを貼り付けると

本文欄にURL 1つだけを貼り付けると、自動で `{{< link-card url="..." >}}` の記法になります。

- Ctrl+Zを1回押すと、記法がURLに戻ります。もう1回でURLも消えます。
- 画像のファイルを貼ったときは、従来どおり画像として入ります。
- 貼り付けた記法の前後には改行を挿入しません。文の途中に貼ったときは、記法の前後で改行して、記法だけの1行にしてください。

### YouTubeのID

`https://www.youtube.com/watch?v=dQw4w9WgXcQ` の `v=` の後ろ（この例では `dQw4w9WgXcQ`）の11字です。IDの形が違うと、記事に赤い文字でエラーが出ます。

### コードの中に書きたいとき

説明のために記法そのものを見せたいときは、`{{</* link-card */>}}` のように `{{</*` と `*/>}}` で囲みます（Hugoのエスケープ）。このときは実行されません。

コードブロック（``` で囲んだ部分）の中の記法は、編集画面のプレビューではカードにしません。公開後の扱いは、確認するまで保証しません。

## 画像

### アップロード

次のどれでも画像を上げられます。画像は `blog-article` の `static/images/<年>/` に保存され、本文には `![名前](/images/年/ランダムな名前.webp)` が入ります。

| 方法 | 確認ダイアログ | 備考 |
| --- | --- | --- |
| ツールバーの画像ボタン | なし | ファイルを選ぶ |
| 本文欄へCtrl+V / Cmd+V | あり | クリップボードの画像 |
| 本文欄へドラッグ＆ドロップ | あり | |
| ツールバーの「画像の一覧」 | なし | 複数のファイルを選べる。ドロップも可 |

- 上げる前に、長辺1600pxに縮小してWebP（品質0.85）に変換します。変換後に1MBを超えると保存できません。GIFとSVGは変換せず、1MBまでです。
- 貼り付けとドロップは、誤って貼った画像を上げないよう、プレビューと「表示サイズ」を選ぶ確認ダイアログが出ます。`blog-article` は公開リポジトリなので、**上げた時点で誰でも見られます**。個人情報などが写っていないか確認してください。
- 上げた画像を後から消しても、Gitの履歴には残ります。

### 表示サイズ

本文では、画像の説明（alt）の末尾に `|` と幅（px）を付けると、その幅で表示します。

```
![設計図|480](/images/2026/abcd1234.webp)
```

- 選べる幅は、確認ダイアログと画像の一覧の選択欄から挿入できます（小320 / 中480 / 大720）。数字は手で書き換えても構いません（2〜4桁）。
- 付けなければ元の大きさです。ページの幅より大きい画像は、ページの幅に収まります。

### 画像の管理

- 編集画面: ツールバーの「画像の一覧」で開くダイアログ。画像を選んで本文のカーソル位置に挿入、URLのコピー、削除ができます。挿入しても閉じないので、続けて挿入できます。
- 管理画面: `/admin/images/`（`/admin/` の「画像」タブ）。一覧、アップロード、URLのコピー、削除。
- 削除は1件ずつです。その画像を使っている記事があるかは調べないので、確認の文面を読んでから消してください。反映まで1〜2分かかります。

### プレビューの画像

公開前の画像は `/images/...` では開けないので、プレビューではGitHub上の画像を直接表示します。上げた直後の画像は手元のデータで表示するので、すぐ見えます。

### サムネイル

一覧のカードの画像は、本文の最初の画像が自動で利用されます。編集画面の「サムネイル」で、本文の画像から選ぶか、別の画像を上げて指定できます。

## 編集画面のそのほか

- **並べて表示**: 画面が広い（1400px以上）ときだけ使えます。このときだけ、ツールバーの右端にスクロール同期の切り替えボタンが出ます。オフにすると、本文欄とプレビューを別々にスクロールできます。選んだ状態は、この端末に覚えます。
