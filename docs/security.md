# セキュリティ

利用者は管理者 1 人です。対策は最小限にしています。

## 権限

- 書き込みの権限は GitHub が判定します。このサイトに独自の認可処理はありません。
- トークンは `blog-article` の Contents（読み書き）だけに絞ります。
- 画面の「管理者向けの表示」は使い勝手のためだけです。実際の権限は GitHub 側で決まります。

## トークン

- `localStorage` にだけ保存します。リポジトリ、HTML、URL、ログには出しません。
- GitHub が 401 を返したら、保存済みのトークンを消してログイン画面へ戻します。
- ログアウトはトークンを消すだけです。GitHub 側のトークンは、利用者が GitHub の設定から失効させてください。

## ブラウザでの扱い

- 外部スクリプトは `marked` だけです。バージョンを固定し、SRI（`integrity`）を付けています。
- Content-Security-Policy で、スクリプトの読み込み元を `self` と `cdn.jsdelivr.net` に限定しています（インラインスクリプトはテーマの初期化に必要なため許可）。
- ユーザーの入力（記事の本文、タイトル、一覧の表示）は `textContent` で描画します。
- `innerHTML` を使うのはプレビューだけです。プレビューは `script`、`iframe` などの要素と、`on*` 属性、`javascript:` の URL を取り除いてから描画します。
- 記事の slug は `^[a-z0-9-]{1,80}$` で検査します。API に渡すパスはこの検査を通ったものだけです。

## 報告

問題を見つけたら、リポジトリの Issue か、管理者へ直接連絡してください。
